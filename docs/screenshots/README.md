# 界面截图（docs/screenshots/）

主 README 的「界面预览」引用本目录下的图片。请按下面的命名放置截图，提交后即可在 README 中显示。

## 需要的截图

| 文件名 | 内容 | 建议 |
|---|---|---|
| `workspace.png` | 工作台：上传区 + 任务列表 + 正文预览 | 选一个已完成任务，正文含表格/公式更直观 |
| `knowledge.png` | 知识库：检索框 + 命中结果 + 高亮片段 | 截一次有命中的检索结果 |
| `admin.png` | 管理后台：用户列表 + 用量统计 | 管理员登录后可见 |

## 拍摄要点

- **尺寸**：宽 1200–1600px 即可（GitHub README 表格里会自适应缩放）
- **格式**：PNG（截图默认即可），文件名与上表一致
- **打码**：若含真实邮箱 / 文件名，请先打码再提交
- **分辨率**：2x 屏截图（Retina）会更清晰

## 如何截图

- 本地模式：`npm start` → 打开 `http://127.0.0.1:3088`，完成一次解析后再截
- 云端模式：登录线上站点，同样流程

## 临时占位

在截图补上之前，主 README 的预览表格会显示"裂图"占位，这是正常的；放入同名 PNG 后自动生效，无需改动 README 正文。
